What I do

I’m a network engineer at AT&T, with experience across RAN wireless and wireline. Day to day, I automate tasks for teams, manage cloud databases, and build cool things.

Why I built this

I like to build, experiment and tinker.

It started because I wanted to build my own wedding website. Then it spiralled:

  • daily games
  • tools for my hobbies: snowboarding, surfing and mountain biking
  • a home for my fantasy football league
  • apps to keep my finances in check
  • ways to game credit cards and travel
  • and more ideas in the works

What it’s built with

The site
HTML, CSS and plain JavaScript (no framework), hosted on GitHub Pages. A small Node script builds the project pages. Anonymous visit counts with GoatCounter, summed up by a Cloudflare Worker.
Snow and Surf Report
JavaScript. GitHub Actions fetches forecasts every hour from Open-Meteo, NOAA (tides and buoys) and USDA SNOTEL. Firebase (Google sign-in and Firestore) for saved settings, with email and push-notification alerts.
Fantasy Football
A Node build from the ESPN fantasy league data, rebuilt on a schedule by GitHub Actions. A Cloudflare Worker runs the Refresh now button.
Budget Ledger
One HTML page with JavaScript. Google sign-in and Google Drive to save the ledger, IndexedDB in the browser, and hand-drawn SVG charts.
Contrail
JavaScript with D3 and TopoJSON maps, airport data from OurAirports, and OpenStreetMap’s Nominatim to find hotels on the map. The demo runs on sample data.
What’s in My Wallet?
JavaScript, with rules that work out which card to use and when to keep or downgrade one. The demo runs on sample data.
Portfolio Ledger (in progress)
JavaScript, with Google sign-in and Google Drive for saving, and a Cloudflare Worker that fetches prices from Finnhub and CoinGecko.
In the workshop
Loop Lab makes its sounds with the Web Audio API. Krillion Code Breaker is plain JavaScript and SVG.
