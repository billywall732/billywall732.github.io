    How the bot plays fair

    • It only reads the screen. Each prompt is read from the page text, the same words you see. It never looks at Krillion’s network traffic, code or storage for answers.
    • One dive a day. The Run button works once per day (Krillion resets at midnight Eastern, 9 PM Pacific), on the bot’s own account.
    • Same clock, one answer. Claude gets the prompt during the countdown and the bot types a single answer inside the 25 seconds, at a human pace.
    • A polite visitor. Ads and analytics are blocked so it never adds fake views to Krillion’s numbers, and if Krillion ever shows a challenge or a rate limit, the bot stops for the day instead of working around it.
